# Demo inputs — The Loom (video recording)

The beats: opening phrase → 2–3 live weaves → an insert edit on the projector → a rewrite edit →
`t` for the time-lapse close. Below are the actual inputs to type at each beat. Phrases that name a
concrete, paintable image weave best (the illustrator gets material, and the audience can see
exactly which words were yours). Throw phrases in one at a time so each thread reads clearly —
but queueing several is fine now (up to 8 pending per phone).

Before recording: restart for a blank story — `tmux respawn-pane -k -t loom` — and check
`/health` says `"round": 0`.

## Set A — the lighthouse (moody, paints beautifully)

| beat | type this |
|---|---|
| opening phrase (phone) | `A lighthouse keeper finds a message in a bottle` |
| weave 1 (phone) | `the tide brings a second bottle` |
| weave 2 (phone) | `a lantern flickers green` |
| weave 3 (phone) | `someone knocks at the lighthouse door` |
| insert edit (projector, dbl-click a settled line, add mid-sentence) | `, written in her own handwriting,` |
| rewrite edit (projector, replace a whole sentence) | `The knocking stopped, and the door opened on its own.` |

## Rules of thumb for improvising

- Phrases: ≤ 120 chars, concrete nouns and one action — `a dragon lands on the hill`, not
  `something dramatic happens`. The phrase lands verbatim, so it should read like story on its own.
- Insert edits: add a short clause INSIDE a sentence (commas included) and change nothing else —
  the loom protects it and blends around it.
- Rewrite edits: replace one full sentence with one full sentence — the neighbours re-weave to
  agree with it.
- Timing: opening takes ~20–40s, every later round ~5–15s. A rejected round ("the loom let that
  one go") retries by itself — keep going, no phrase is ever lost.
